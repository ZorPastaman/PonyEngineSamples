# World samples

Shows how to use the world module.

The world module in Pony Engine is based on ECS pattern. It provides the infrastructure for management of worlds
that contain entities and components.
Also, a world may contain objects that are referenced from components with special handles.

## Samples

| Sample                      | Description                                                    |
|:----------------------------|:---------------------------------------------------------------|
| [WorldComponent](Component) | Shows how to make a component for the world module and use it. |
| [WorldObject](Object)       | Shows how to make an object for the world module and use it.   |
