# Time samples

Shows how to use the time module.

The time module provides some enhanced time management over those things that the application module provides.
It has concepts of real time, virtual time and unscaled virtual time.
It uses time scale and time cap for the virtual time.
Also, it calculates time steps. You can set a time step length and every frame the time module will calculate how many steps elapsed
for real, virtual and unscaled virtual time.
